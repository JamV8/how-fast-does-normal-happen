Does the rule of 30 hold outside the textbook? (extension beyond the assignment)

Show the setup code 
source("../R/clt_functions.R")

# Treat a real dataset as the population: each observation in a sample is
# drawn at random (with replacement) from the dataset.
from_data <- function(x) function(n) sample(x, n, replace = TRUE)
pop_sd    <- function(x) sqrt(mean((x - mean(x))^2))   # SD of the whole population (divide by N)

Textbook distributions are useful because their properties are known exactly. But the reason anyone cares about the Central Limit Theorem is real data: prices, waiting times, delays, populations. This page applies the same method and the same “normal enough” standard to real datasets.

How it works. Each dataset is treated as a complete population. A “sample of size n” means picking n records at random from it, each pick independent of the others (with replacement). Then everything is the same as before: 100,000 samples per n, the four checks, and the smallest n that passes.

Part A. Warm-up: two examples that shaped my predictions

I worked through these two examples before making my predictions for the five assigned populations.

River lengths: one sample, then thousands

R’s rivers dataset gives the lengths of the 141 longest rivers in North America. Most rivers are a few hundred miles long, but a few giants (up to 3,710 miles) create a long right tail.

Even at n = 30 the means are still clearly skewed (skewness 0.59). The formula skewness/√n predicts 0.58, and the simulation agrees. This was my first sign that n = 30 is not a universal answer.

Caveats I noted. (1) This dataset contains only the longest rivers, so it says nothing about rivers in general: a bigger sample cannot fix a biased population. (2) Sampling without replacement from only 141 rivers would behave differently. At n = 141 every sample would be the whole dataset and the mean would never vary. That is why the main study samples from theoretical distributions, where every draw is independent.

An election poll: where the CLT is used every day

A poll asks n = 1,000 people a yes/no question. Suppose the true support is 52%. Each answer is a 0 or 1, which is about as far from a bell curve as possible, yet the CLT says the poll result is approximately normal.

Show code 
p <- 0.52; n_poll <- 1000
set.seed(student_id)
polls <- simulate_means(function(k) rbinom(k, 1, p), n_poll)
se_p  <- sqrt(p * (1 - p) / n_poll)
inside <- mean(abs(polls - p) <= 1.96 * se_p)
style_par(mar = c(4, 4, 1, 1))
hist(100 * polls, breaks = seq(floor(100 * min(polls)) - 0.05, ceiling(100 * max(polls)) + 0.05, by = 0.1),
     freq = FALSE, col = adjustcolor(pal$bars, 0.75), border = NA,
     xlab = "Poll result (% saying yes)", ylab = "Density", main = "")
rect(100 * (p - 1.96 * se_p), 0, 100 * (p + 1.96 * se_p), 1, col = adjustcolor(pal$zone, 0.12), border = NA)
curve(dnorm(x, 100 * p, 100 * se_p), add = TRUE, col = pal$curve, lwd = 2.2, n = 400)

A pollster runs one poll and reports “52% ± 3.10 points”. That margin comes from the CLT formula, 1.96·√(p(1−p)/n), not from repeating the poll. The simulation checks the promise: 94.7% of the simulated polls landed inside the margin, close to the promised 95%. In real life B = 1 (one poll); in a simulation we can afford B = 100,000 and see whether the formula is honest.

Prediction first, then simulation

For each dataset I first predicted the threshold from its skewness, n ≈ (skewness / 0.25)², the same formula that predicted 64 for the exponential, and then ran the full two-stage search.

What the real data show

  • The rule of 30 fails for most real-world data. It works for the geyser, whose distribution is bimodal but nearly symmetric. It does not work for prices, delays, or populations, which are the kind of data analysts handle every day. These need roughly 51, 235 and 2,450 observations.
  • The skewness formula predicts the threshold well, even for messy real data: the simulated n lands near (skewness/0.25)² for the continuous datasets. One number about the population, its skewness, tells you most of what you need to know.
  • Discrete counts behave like the binomial. The inventions data pass the skewness check early but need extra observations because of the steps between possible values. This is the same pattern as in the binomial analysis.
  • Heavy tails make the CLT slow. County populations have finite variance, so the CLT does eventually apply, but only after thousands of observations. In practice that is not far from the Cauchy case. With a few giants in the data, the mean of a typical sample is dominated by whether a giant was included.

Limits of this extension

  • The dataset is treated as the whole population. Real conclusions would also depend on how the data were collected.
  • Independence is assumed. Real flight delays on the same day are correlated (one storm delays many flights), which would slow convergence further. The extra-credit dependent-process study is the place to examine this.
  • Resampling with replacement keeps the draws independent and identically distributed, matching the CLT’s assumptions.
