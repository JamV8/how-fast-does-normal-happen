Extremely heavy tails: the case where the CLT does not apply

Show the simulation code 
source("../R/clt_functions.R")

rgen <- function(n) rcauchy(n, location = 0, scale = 1)
# The Cauchy distribution has no mean and no variance, so mu and sigma are NA.
# The tail check then uses the simulated mean and SD of the sample means.

coarse <- c(1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 5000)
exper  <- run_with_refinement(rgen, coarse)

res    <- exper$results
n_main <- smallest_normal_n(res)          # NA = never normal enough
n_std  <- n_by_standard(res)
at     <- function(k) res[res$n == k, ]

save_results(res, "cauchy")
save_summary(res, "Cauchy(0, 1)", n_main, prediction = "never",
             key_note = "No finite variance: the mean of n values has the same distribution as one value")

# Quartiles and other quantiles of the sample means at each n
qs <- t(sapply(exper$means, quantile, probs = c(0.10, 0.25, 0.50, 0.75, 0.90)))

No n is large enough. The sampling distribution of the mean never becomes normal, under any of my three standards (tested up to n = 5,000; my prediction: never).

1. What population am I sampling from?

The Cauchy distribution looks like a bell curve near the middle, but its tails are so heavy that extreme values keep appearing no matter how much data you collect. For example, about 6% of draws are farther than 10 from the center; for a normal distribution with the same peak the chance is essentially zero.

Property Value
Center (median) 0
Quartiles −1 and +1
Mean μ does not exist
Standard deviation σ does not exist (infinite variance)
Skewness, kurtosis do not exist
Theoretical SE of the mean not defined

The CLT requires a finite variance, so its conditions fail here.

curve(dnorm(x, 0, sqrt(pi / 2)), add = TRUE, col = "gray45", lwd = 2, lty = 2)
legend("topright", c("Cauchy(0, 1)", "Normal, same peak height"), col = c(pal$curve, "gray45"),
       lwd = 2, lty = c(1, 2), bty = "n")

2. What did I expect before running the simulation?

Never. The Cauchy has no finite mean or variance, so the CLT conditions fail. In my pilot run the quantiles of the sample means at n = 100 were the same as at n = 1, so averaging did not seem to help.

3. Which sample sizes did I investigate?

n = 1, 2, 5, 10, 20, 50, 100, 200, 500, 1,000, 2,000, 5,000, which is a much wider range than for the other populations, to check whether anything changes at very large n. B = 100,000 sample means per n, seed 9426. No refinement was possible because no n passed.

4. Results

The usual statistics are meaningless here

The skewness and kurtosis take enormous values that change sign at random from one n to the next, and the SD of the means does not shrink like 1/√n. Each of these numbers is decided by the single most extreme value among the 100,000 means. Because the true moments do not exist, these statistics estimate nothing, so for this population I rely on quantiles and pictures instead.

The middle of the distribution never shrinks

The interquartile range stays at about 2.00 at every n, the same as for a single observation. For any population with a finite variance the IQR of the mean would shrink by a factor of √n: about 10 times smaller at n = 100 and 70 times smaller at n = 5,000.

A useful contrast: the median does converge

Show code 
n_med <- c(1, 5, 10, 50, 100, 500, 1000)
set.seed(student_id)
iqr_mean   <- sapply(n_med, function(k) IQR(replicate(20000, mean(rcauchy(k)))))
iqr_median <- sapply(n_med, function(k) IQR(replicate(20000, median(rcauchy(k)))))
style_par(mar = c(4, 4.4, 1, 1))
plot(n_med, iqr_mean, log = "xy", type = "b", pch = 19, col = pal$curve, ylim = range(c(iqr_mean, iqr_median)),
     xlab = "n (log scale)", ylab = "IQR of the statistic (log scale)")
lines(n_med, iqr_median, type = "b", pch = 17, col = pal$bars)
legend("bottomleft", c("sample mean", "sample median"), pch = c(19, 17), col = c(pal$curve, pal$bars), bty = "n")

The problem is not the data but the statistic. The sample median ignores how far away the extreme values are, so it settles down even for the Cauchy. The sample mean gives every extreme value full weight.

5. When did the sampling distribution become approximately normal?

\[\boxed{\text{No value of } n}\]

Every check failed at every sample size from 1 to 5,000, under the strict, main and lenient standards alike.

6. Why did I choose that answer?

  • Theory: the average of n independent Cauchy(0, 1) values is again exactly Cauchy(0, 1). Adding more data does not change the distribution of the mean at all, so there is no n at which it becomes normal.
  • Simulation: the quartiles of the sample means stayed at about −1 and +1 from n = 1 to n = 5,000 (IQR ≈ 2.00 throughout), the histograms overlap the Cauchy density at every n, and the running mean of a single long sequence never settles.
  • Why the CLT fails: the CLT needs a finite variance. One extreme value in a sample can outweigh all the others, so averaging does not cancel out the extremes as it does for the other populations.
  • Practical lesson: “the sample is large” is not enough to justify a normal approximation. For data with extremely heavy tails, a robust statistic such as the median is the better tool.

7. What surprised me?

I predicted it would never become normal, and it did not. What I did not expect was how little changed. I asked for an extra pilot at n = 100 to see if a bigger sample would help at least slightly, but the middle half of the sample means still went from about −1 to 1, the same as for single values. At n = 5,000 it was still the same, and the skewness kept jumping between large positive and negative values. This matches the theory: the mean of n standard Cauchy values has exactly the same distribution as one value, so averaging does not help. A single extreme value can outweigh the rest of the sample.

## 6. Why did I choose that answer?

- **Theory:** the average of n independent Cauchy(0, 1) values is again exactly Cauchy(0, 1). Adding more
  data does not change the distribution of the mean at all, so there is no n at which it becomes normal.
- **Simulation:** the quartiles of the sample means stayed at about −1 and +1 from n = 1 to

  Cauchy density at every n, and the running mean of a single long sequence never settles.
- **Why the CLT fails:** the CLT needs a finite variance. One extreme value in a sample can outweigh all
  the others, so averaging does not cancel out the extremes as it does for the other populations.
- **Practical lesson:** "the sample is large" is not enough to justify a normal approximation. For data
  with extremely heavy tails, a robust statistic such as the median is the better tool.
