Discrete counts of a rare event: highly skewed and lumpy

source("../R/clt_functions.R")

rgen  <- function(n) rbinom(n, size = 5, prob = 0.1)  # n counts, each 0..5
mu    <- 5 * 0.1                                     # 0.5
sigma <- sqrt(5 * 0.1 * 0.9)                         # 0.671
pop_skew <- (1 - 2 * 0.1) / sigma                    # 1.19
pop_kurt <- (1 - 6 * 0.1 * 0.9) / (5 * 0.1 * 0.9)    # 1.02

coarse <- c(1, 2, 5, 10, 15, 20, 25, 30, 40, 50, 60, 75, 100, 125, 150, 200,
            300, 400, 500, 600, 700, 800, 900, 1000, 1250, 1500, 2000)
exper  <- run_with_refinement(rgen, coarse, mu, sigma)

res    <- exper$results
n_main <- smallest_normal_n(res)
n_std  <- n_by_standard(res)
at     <- function(k) res[res$n == k, ]

save_results(res, "binomial")
save_summary(res, "Binomial(5, 0.1)", n_main, prediction = "100",
             key_note = "Skewness passes early; discreteness (Q-Q steps, jumping tails) sets n")

1. What population am I sampling from?

Each observation counts the successes in 5 tries when each try succeeds with probability 0.1. Think of the number of defective items in a box of five, or the number of goals a player scores in five shots. Most of the time the answer is 0, sometimes 1, and rarely more.

Property Value
Possible values 0, 1, 2, 3, 4, 5
Mean μ np = 0.5
Standard deviation σ √(np(1−p)) ≈ 0.671
Skewness (1−2p)/σ ≈ 1.19 (right skew)
Excess kurtosis ≈ 1.02
Theoretical SE of the mean 0.671/√n

2. What did I expect before running the simulation?

n = 100. The binomial is less skewed than the exponential, but its values are discrete: the sample mean can only move in steps of 1/n. In my pilot run the histogram still looked lumpy at n = 20, so I expected it to need more observations than the exponential before its graph looks smooth and normal.

5. When did the sampling distribution become approximately normal?

\[\boxed{n = 83}\]

6. Why did I choose that value?

  • Skewness was not the problem. It dropped below 0.25 at n = 30, close to the theoretical (1.19/0.25)² ≈ 23.
  • Discreteness was. The Q-Q correlation and the tail check passed only at n = 75 and n = 83. Near the threshold the tail rates jump as possible values of the mean cross the ±1.96 SE boundary. n = 76 already passes, but n = 82 fails again, so I do not stop there.
  • At n = 83 all four checks pass (skewness 0.140, Q-Q r 0.9983, tails 2.13% / 2.87%), and so does every larger n I tested, up to 2,000.
  • n = 30 is not enough: the skewness passes there, but the Q-Q correlation is 0.9955 and the tails are 1.44% / 2.60%.

7. What surprised me?

I expected the exponential and the binomial to end up far apart, since the exponential is much more skewed (2.0 vs 1.19). Under my main standard they were actually close: 71 for the exponential and 83 for the binomial. The results table shows that they fail for different reasons. The exponential is held back by its skewness, which decreases as 2/√n. The binomial already passed the skewness check at n = 30. What held it back was the Q-Q correlation and the tail check, because its sample mean can only take values in steps of 1/n. Its Q-Q plot looks like a staircase, and the tail check passes and fails again at neighbouring n.

The bigger surprise for me was the strict standard. There the binomial needed about 900, compared with about 600 for the exponential, even though it is less skewed. My explanation is that with a narrow tail tolerance, the steps in the binomial mean matter more than its skewness. Compared to the die, each step is about 2.5 times bigger relative to the standard error (σ = 1.71 for the die vs 0.67 here), so it takes much longer to smooth out.

### Why the tail check jumps around


standard errors. So one more or one fewer possible value inside the boundary changes the tail rate
noticeably. That is why the pass/fail result flips between neighbouring sample sizes.

## 6. Why did I choose that value?

- **Skewness was not the problem.** It dropped below 0.25 at n = `r first_stable_n(res$n, res$skew_ok)`,
  close to the theoretical (1.19/0.25)² ≈ 23.
- **Discreteness was.** The Q-Q correlation and the tail check passed only at
  n = `r first_stable_n(res$n, res$qq_ok)` and n = `r first_stable_n(res$n, res$tail_ok)`. Near the
  threshold the tail rates jump as possible values of the mean cross the ±1.96 SE boundary.
  `r flip_text(res, n_main)`
- At **n = `r n_main`** all four checks pass (skewness `r f3(at(n_main)$skewness)`, Q-Q r
  `r f4(at(n_main)$qq_cor)`, tails `r pct(at(n_main)$lower_tail, 2)` / `r pct(at(n_main)$upper_tail, 2)`),
  and so does every larger n I tested, up to 2,000.
- **n = 30 is not enough:** the skewness passes there, but the Q-Q correlation is `r f4(at(30)$qq_cor)`
  and the tails are `r pct(at(30)$lower_tail, 2)` / `r pct(at(30)$upper_tail, 2)`.
